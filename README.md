# flomo+滴答 同步插件

### 功能介绍

> 将 [flomo](https://v.flomoapp.com/) 与 [滴答清单](https://dida365.com/) 收集箱的内容同步到思源（自动从上次同步时间处开始）

1. 支持将 flomo 中的 memo 同步到指定文档或指定笔记本的 daily notes 中。
2. 支持筛选或排除某些标签同步 flomo。
3. 支持将滴答清单（中国版 dida365）**收集箱**中未同步的任务同步到**与 flomo 相同**的思源目标位置（纯文字写入，带建立时间前缀）。
4. 同步成功后会**删除**滴答收集箱中的原任务，避免重复同步。

设置界面分为 **flomo** / **滴答** 两个 Tab。

### 配置介绍：

#### flomo Tab

* `启用 flomo 同步`：可单独开关；关闭后顶栏同步会跳过 flomo（默认开启，兼容旧配置）。
* 先在插件设置中，配置 flomo 账号和密码（启用时必填；若只用滴答可关闭开关）。
* `上次同步时间`一般不用填，会自动记录上次同步时间，第一次使用为空时自动取今天00:00:00。根据需要，可手动设置为想要同步的起始时间。格式必须按照：`YYYY-MM-DD HH:mm:ss`，如`2023-12-08 12:12:12` 。
* `回写同步成功标签` 在同步成功后，是否根据需要给 flomo 的 memo 用标签加一个同步标识，如：`已同步`，不用写`#`。默认不回写。
* `写入思源位置方案`选择同步到 daily note 或者指定页，分别对应下面的`dailynote笔记本id`和`指定文档id`（**滴答清单共用此目标**）。
* `同步标签方案`是选择排除某些标签还是包含某些标签来同步。默认采用排除标签方案，不填写内容就是所有都支持。 `同步排除标签` 和`同步包含标签`可以填单标签，也可以填多标签，中间用空格隔开。
* `accessToken` 不用管这个，由账户和密码自动生成。

#### 滴答 Tab

* `启用滴答同步`：打开后，点击顶栏同步按钮会一并同步收集箱。
* `滴答 API Token`：在滴答清单网页 → 头像 → 设置 → 账号 → **API Token** 中创建并粘贴到此处。请勿把含 Token 的配置备份分享给他人。
* 同步写入思源成功后，会调用 Open API **删除**对应收集箱任务（不可恢复，请确认收集箱内容可清空）。
* `滴答上次同步时间`：仅同步该时间之后创建/更新的收集箱任务；为空则默认为今天 0 点，并会在同步后自动更新。

当前仅支持中国版 `api.dida365.com`，范围限于**收集箱**。
